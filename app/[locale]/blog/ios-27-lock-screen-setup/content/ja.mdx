# iOS 27でスッキリしたロック画面を設定する方法（コンパクト時計とワンタップ起動のアプリ）

**結論：** ロック画面を長押しして**カスタマイズ**をタップし、壁紙を選んで、iOS 27のコンパクト時計のオプションをオンにすると、時刻が占める場所が小さくなります。あとはアプリを追加するだけです。[WidgetLoft](/widgetloft)（旧FolderMini）のロック画面ウィジェットは1列に最大4個のアプリを置け、クイック起動バーならロック画面に最大10個のアプリを並べられます。

iOS 27では、ロック画面に余白が生まれます。その余白は大きな時計ではなく、実際によく開くアプリのために使うのがいちばんです。

---

## iOS 27でロック画面はどう変わったか

スッキリした設定に関係するiOS 27の変更は2つです。

- **コンパクト時計。** 時刻が小さくなり、画面中央を占めるのではなく、上部の日付とウィジェットの横に収まります。
- **壁紙拡張。** 写真を広げてロック画面全体を埋められます。サイズが合わない写真に便利です。

それでもiOSには、タップして開けるアプリの列がありません。標準のロック画面ウィジェットは情報を表示するもので、ほかのアプリを起動しません。この穴を埋めるのが[WidgetLoft](/widgetloft)で、道具は2つあります。いつも表示されているロック画面ウィジェットと、より多くのアプリを並べられるライブアクティビティ「クイック起動バー」です。

## 手順：iOS 27でスッキリしたロック画面を作る

1. **壁紙を選ぶ。** ロック画面を長押しして**カスタマイズ**をタップし、写真を選びます。画面いっぱいにならない場合は、iOS 27の壁紙拡張で広げます。
2. **コンパクト時計をオンにする。** 同じ編集画面でコンパクト時計のオプションを選びます。時刻が上部の日付とウィジェットの横に移動します。
3. **WidgetLoftのロック画面ウィジェットを追加する。** WidgetLoftで、よく使うアプリのグループを作ります。ロック画面の編集画面に戻り、**WidgetLoft**ウィジェットを追加してそのグループを選びます。1列に最大4個（大きいアイコンでは3個）のアプリが並びます。
4. **クイック起動バーをオンにする。** WidgetLoftを開き、**設定 → ダイナミックアイランドとライブアクティビティ**で**クイック起動バー**（ベータ）をオンにします。
5. **グループを選ぶ。** **フォルダ**で表示したいグループを選びます。ロック画面のバナーには最大10個、ダイナミックアイランドには最大5個のアプリが表示されます。

## ロック画面ウィジェットとクイック起動バーの比較

| | ロック画面ウィジェット | クイック起動バー |
| --- | --- | --- |
| アプリ数 | 1列に最大4個（大きいアイコンでは3個） | ロック画面に最大10個、ダイナミックアイランドに最大5個 |
| 表示される期間 | ロック画面の一部として常に表示 | WidgetLoftを開いてから数時間 |
| ロック画面でのタップ | まずロック解除、その後アプリが開く | まずFace IDでロック解除、その後アプリが開く |
| ダイナミックアイランド | 対象外 | アイランドを長押ししてアプリをタップすれば、ワンタップで開く |

どちらか一方を選ぶ必要はありません。一日中開く4個のアプリはウィジェットに入れ、しばらく手元に置きたい長めのリストはクイック起動バーに任せましょう。アイランド側の詳しい使い方は、[ダイナミックアイランドにアプリを置く方法](/blog/apps-in-dynamic-island-iphone)をご覧ください。

## よくある質問

**ロックを解除せずにロック画面からアプリを開けますか？**
いいえ。ロック画面では、ウィジェットもクイック起動バーも、まず（Face IDなどで）ロック解除を求め、その後にアプリを開きます。途中でWidgetLoftが一瞬表示されることがあります。ダイナミックアイランドでは、アプリはワンタップで開きます。

**ロック画面からクイック起動バーが消えたのはなぜですか？**
iOSはライブアクティビティを数時間で終了します。WidgetLoftはアプリを開くたびにバーを再開します。まったく表示されない場合は、iOSの設定でWidgetLoftのライブアクティビティが許可されているか確認してください。

**この設定にはiOS 27が必要ですか？**
必要なのはコンパクト時計と壁紙拡張だけです。[WidgetLoft](/widgetloft)自体はiOS 18以降で動作します。知っておきたい制限が1つあります。ロック画面ウィジェットに表示されるのはトップレベルのアプリだけで、グループ内のフォルダは表示されません。
