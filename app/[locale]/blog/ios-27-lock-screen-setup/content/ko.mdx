# iOS 27에서 깔끔한 잠금 화면 설정하는 방법 (컴팩트 시계와 한 번 탭으로 여는 앱)

**빠른 답변:** 잠금 화면을 길게 누르고 **사용자화**를 탭한 뒤, 배경화면을 고르고 iOS 27의 컴팩트 시계 옵션을 켜서 시간이 차지하는 공간을 줄이세요. 그다음 앱을 추가합니다. [WidgetLoft](/widgetloft) (구 FolderMini) 잠금 화면 위젯은 한 줄에 최대 4개의 앱을 담고, 빠른 실행 바는 잠금 화면에 최대 10개의 앱을 올려 줍니다.

iOS 27은 잠금 화면에 여유 공간을 더 줍니다. 그 공간은 더 큰 시계보다 실제로 자주 여는 앱에 쓰는 것이 가장 좋습니다.

---

## iOS 27에서 잠금 화면이 바뀐 점

깔끔한 설정에 중요한 iOS 27의 변화는 두 가지입니다.

- **컴팩트 시계.** 시간이 작아져 화면 가운데를 채우지 않고 위쪽의 날짜와 위젯 옆에 자리 잡습니다.
- **배경화면 확장.** iOS가 사진을 넓혀 잠금 화면 전체를 채울 수 있어, 크기가 딱 맞지 않는 사진에 유용합니다.

그래도 iOS에는 여전히 탭해서 여는 앱 줄이 없습니다. 기본 잠금 화면 위젯은 정보를 보여 줄 뿐 다른 앱을 실행하지 않습니다. 이 빈자리를 [WidgetLoft](/widgetloft)가 두 가지 도구로 채웁니다. 항상 떠 있는 잠금 화면 위젯, 그리고 더 긴 앱 목록을 담는 실시간 현황인 빠른 실행 바입니다.

## 단계별 안내: iOS 27에서 깔끔한 잠금 화면 만들기

1. **배경화면 고르기.** 잠금 화면을 길게 누르고 **사용자화**를 탭한 다음 사진을 고릅니다. 화면을 다 채우지 못하면 iOS 27의 배경화면 확장으로 넓히세요.
2. **컴팩트 시계 켜기.** 같은 편집 화면에서 컴팩트 시계 옵션을 고릅니다. 시간이 위쪽 날짜와 위젯 옆으로 이동합니다.
3. **WidgetLoft 잠금 화면 위젯 추가하기.** WidgetLoft에서 자주 쓰는 앱으로 그룹을 만듭니다. 잠금 화면 편집 화면으로 돌아와 **WidgetLoft** 위젯을 추가하고 그 그룹을 고르세요. 한 줄에 최대 4개(큰 아이콘은 3개)의 앱이 표시됩니다.
4. **빠른 실행 바 켜기.** WidgetLoft를 열고 **설정 → Dynamic Island 및 실시간 현황**으로 가서 **빠른 실행 바**(베타)를 켭니다.
5. **그룹 고르기.** **폴더**에서 원하는 그룹을 고릅니다. 잠금 화면 배너에는 최대 10개, Dynamic Island에는 최대 5개의 앱이 나타납니다.

## 잠금 화면 위젯과 빠른 실행 바 비교

| | 잠금 화면 위젯 | 빠른 실행 바 |
| --- | --- | --- |
| 앱 수 | 한 줄에 최대 4개(큰 아이콘은 3개) | 잠금 화면에 최대 10개, Dynamic Island에 최대 5개 |
| 표시 시점 | 잠금 화면의 일부로 항상 표시 | WidgetLoft를 연 뒤 몇 시간 동안 |
| 잠금 화면에서 탭 | 먼저 잠금 해제, 그다음 앱이 열림 | 먼저 Face ID로 잠금 해제, 그다음 앱이 열림 |
| Dynamic Island | 포함되지 않음 | 아일랜드를 길게 누르고 앱을 탭하면 한 번에 열림 |

둘 중 하나만 고를 필요는 없습니다. 하루 종일 여는 앱 4개는 위젯에 넣고, 한동안 가까이 두고 싶은 더 긴 목록은 빠른 실행 바에 맡기세요. 아일랜드 쪽이 더 궁금하다면 [Dynamic Island에 앱을 넣는 방법](/blog/apps-in-dynamic-island-iphone)을 읽어 보세요.

## 자주 묻는 질문

**잠금을 해제하지 않고 잠금 화면에서 앱을 열 수 있나요?**
아니요. 잠금 화면에서는 위젯과 빠른 실행 바 모두 먼저 잠금 해제(예: Face ID)를 요청한 뒤 앱을 엽니다. 그 사이에 WidgetLoft가 잠깐 보일 수 있습니다. Dynamic Island에서는 앱이 한 번 탭으로 열립니다.

**빠른 실행 바가 잠금 화면에서 사라진 이유는 무엇인가요?**
iOS는 실시간 현황을 몇 시간 후에 종료합니다. WidgetLoft는 앱을 열 때마다 바를 다시 시작합니다. 전혀 나타나지 않는다면 iOS 설정에서 WidgetLoft의 실시간 현황이 허용되어 있는지 확인하세요.

**이 설정에 iOS 27이 필요한가요?**
컴팩트 시계와 배경화면 확장에만 필요합니다. [WidgetLoft](/widgetloft) 자체는 iOS 18 이상에서 작동합니다. 알아 둘 제한이 하나 있습니다. 잠금 화면 위젯은 최상위 앱만 보여 주므로 그룹 안의 폴더는 표시되지 않습니다.
