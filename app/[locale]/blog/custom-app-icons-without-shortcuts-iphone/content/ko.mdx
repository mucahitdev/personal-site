# 단축어 앱 없이 iPhone 앱 아이콘을 바꾸는 방법

**빠른 답변:** 타일마다 디자인할 수 있는 위젯에 앱을 넣으면 단축어 앱 없이도 앱 아이콘을 꾸밀 수 있습니다. [WidgetLoft](/widgetloft) (구 FolderMini)에는 아이콘 스튜디오가 들어 있어 사진, SF Symbol, 이모지, 글자 중에서 고르고 색을 정한 뒤 라이트와 다크 버전을 따로 만들 수 있습니다. 타일은 여전히 앱을 바로 엽니다.

감성적인 홈 화면은 보통 서로 어울리는 아이콘에서 시작합니다. 대부분의 튜토리얼이 소개하는 방법과 그 방법으로 실제로 얻는 것, 그리고 위젯으로 같은 분위기를 내는 방법을 알아봅니다.

---

## 단축어 방식은 어떻게 작동하나요

가장 많이 공유되는 튜토리얼은 이렇습니다. 단축어 앱을 열고 'App 열기' 동작으로 새 단축어를 만든 다음 앱을 고르고, 이름과 사진 속 이미지를 지정해 홈 화면에 추가합니다. 새 아이콘은 직접 꾸민 앱 아이콘처럼 보입니다.

잘 작동하지만, 실제로 무엇을 얻는지 알아 두면 좋습니다.

- **앱이 아니라 단축어입니다.** 탭하면 단축어 앱을 거쳐서 앱이 열립니다.
- **아이콘이 두 개가 됩니다.** 원래 앱은 그대로 설치되어 있어서 기본 아이콘도 어딘가에 남아 있습니다. 대부분 페이지를 깔끔하게 하려고 앱 보관함으로 옮깁니다.
- **한 번에 아이콘 하나씩.** 앱마다 단축어를 따로 만들고 이름을 붙여야 하며, 라이트와 다크 모두 이미지 한 장을 씁니다.

아이콘 한두 개라면 괜찮습니다. 페이지 전체를 테마로 꾸미려면 위젯이 더 편한 경우가 많습니다.

## 단계별 안내: WidgetLoft로 앱 아이콘 꾸미기

1. **앱 추가하기.** [WidgetLoft](/widgetloft)를 열고 앱 안에서 App Store를 검색하거나(또는 App Store 페이지에서 공유 → WidgetLoft) 앱을 그룹에 추가합니다.
2. **아이콘 변경 열기.** **라이브러리** 탭에서 앱 타일을 탭한 다음 **아이콘 변경**을 탭합니다.
3. **소스 고르기.** **사진**(자를 때 드래그로 이동, 핀치로 확대), **기호**(27개 카테고리의 SF Symbols 5,700개 이상, 영어로 검색), **이모지**, **Mono**(첫 글자, 단어별, 또는 최대 3자의 직접 입력) 중에서 고릅니다.
4. **라이트와 다크 색상 설정하기.** **아이콘 색상**과 **배경**을 고르거나, 위젯 위에 기호만 올리려면 **배경 없음**을 선택합니다. 두 가지 모양 모두에 어울리도록 라이트와 다크 버전을 따로 디자인하세요.
5. **위젯 배치하기.** 홈 화면의 빈 곳을 길게 누르고 위젯을 추가해 WidgetLoft와 크기를 고릅니다. 타일을 탭하면 앱이 바로 열립니다.

## 단축어 방식과 WidgetLoft 아이콘 스튜디오 비교

| | 단축어 방식 | WidgetLoft 아이콘 스튜디오 |
| --- | --- | --- |
| 앱이 열리는 방식 | 단축어 앱을 거쳐 실행 | 타일이 앱을 바로 엶 |
| 다크 버전 | 두 모양에 이미지 한 장 | 라이트와 다크를 따로 디자인 |
| 아이콘당 단계 | 새 단축어, 앱 선택, 홈 화면에 추가, 이미지와 이름 | 타일 탭, 아이콘 변경, 소스와 색상 선택 |
| 아이콘 소스 | 사진 속 이미지 | 사진, SF Symbols 5,700개 이상, 이모지, Mono 글자 |
| 여러 앱 한꺼번에 | 단축어마다 홈 화면 아이콘 하나 | 위젯 하나에 여러 타일 |

차이는 수고가 어디에 들어가느냐입니다. [WidgetLoft](/widgetloft)에서는 디자인과 실행이 같은 타일에 함께 있습니다. 앱마다 단축어를 더 만들 필요가 없고, 탭할 때 단축어 앱이 끼어들지도 않습니다. 커스텀 디자인을 하지 않은 앱은 실제 아이콘으로 표시되므로 원하는 앱만 꾸미면 됩니다.

## 자주 묻는 질문

**WidgetLoft의 커스텀 아이콘은 단축어 앱을 거치나요?**
아니요. 홈 화면의 WidgetLoft 앱 타일은 커스텀 아이콘 여부와 관계없이 번들 ID(bundle ID)로 앱을 바로 엽니다.

**iPhone에 있는 앱의 실제 아이콘도 바뀌나요?**
아니요. 디자인은 위젯 안의 타일에 적용됩니다. 앱 자체의 아이콘은 그대로이고, 앱 보관함에 두면 페이지에는 위젯만 보이게 할 수 있습니다.

**커스텀 아이콘을 다크 모드에서 다르게 보이게 할 수 있나요?**
네. 아이콘 스튜디오에서 라이트와 다크를 따로 디자인할 수 있습니다. 다크 버전을 만들지 않아도 인기 앱에는 미리 준비된 다크 아이콘이 있습니다([iPhone 다크 모드 앱 아이콘](/blog/dark-mode-app-icons-iphone) 참고).
