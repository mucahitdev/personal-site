# iPhoneですべてのアプリのアイコンをダークモード対応にする方法

**手っ取り早い答え：** iOSが本物のダークアイコンを表示できるのは、アプリの開発者がダーク版を用意している場合だけです。そのため多くのアプリが明るいまま残ります。すべてのアプリをダークアイコンにしたいなら、[WidgetLoft](/widgetloft)（旧FolderMini）のウィジェットにアプリを入れましょう。人気アプリには用意済みのダークアイコン、Appleのアプリには本物のダークアイコンがあり、それ以外のアプリにも追加したときにiPhone上でダークアイコンが作られます。

ダークアイコンをオンにしてホーム画面は最高の見た目に。ところが、白い銀行アプリや派手なショッピングアプリのアイコンだけが隅で光っている。なぜそうなるのか、どう直すのかを説明します。

---

## ダークモードでも明るいままのアイコンがある理由

ダークアイコンは、iOSが自動で塗り替えてくれるものではありません。開発者がダーク版をデザインし、アプリに同梱する必要があります。Appleのアプリには用意されていて、多くの大手アプリにもありますが、このアップデートを受けていないアプリもたくさんあります。そうしたアプリのアイコンは、どの外観を選んでも白や明るい背景のままです。

そのアイコン自体は変えられません。できるのは、タイルにダーク版を表示するウィジェットからアプリを開くことです。[WidgetLoft](/widgetloft)はアプリのグループをホーム画面ウィジェットに変え、タイルをタップすると、ショートカットを挟まずにアプリが直接開きます。

## 手順：すべてのアプリをダークアイコンにする

1. **グループを作る。** App Storeから[WidgetLoft](/widgetloft)をインストールし（無料で試せます）、**グループ**タブでグループを作ります。
2. **アプリを追加する。** アプリ内でApp Storeを検索するか、App Storeの任意のページで**共有 → WidgetLoft**を使います。2.1.0の新機能：カタログにないアプリも、追加したときにそのアプリ自身のアイコンからスマホ上でダークアイコンが作られます。何もアップロードされません。
3. **ウィジェットを置く。** ホーム画面を長押しし、**+** をタップしてWidgetLoftを検索し、グループのウィジェットを追加します。
4. **アイコンの外観を選ぶ。** **設定 → ウィジェット → ダークアイコンの外観**を開きます。通常のウィジェットは**自動**（デバイスに合わせる）、**ライト**、**ダーク**から選べます。
5. **タイルを個別に調整する。** 自分好みにしたい場合は、**ライブラリ**でタイルをタップし、**アイコンを変更**からライト用とダーク用に別々の写真を設定します。

## iOS標準のダークアイコンとWidgetLoftウィジェットのダークアイコンの比較

| iOS標準のダークアイコン | WidgetLoftウィジェットのダークアイコン |
| --- | --- |
| 開発者が作った分だけダークになる | 人気アプリには用意済みのダークアイコン |
| AppleのアプリはAppleのダークアイコンを使う | Appleのアプリはここでも本物のダークアイコンを使う |
| ダーク版のないアプリは明るいまま | それ以外のアプリも追加時にiPhone上でダークアイコンが作られる |
| アイコンはアプリに入っているものだけ | どのタイルにもライト用とダーク用の写真を別々に設定できる |
| システムの外観に従う | 「設定」→「ウィジェット」で自動、ライト、ダークを選べる |

その結果、ダークアイコンを出していないアプリも含めて、すべてのタイルがそろったホーム画面になります。すでにWidgetLoftを使っている場合は、新しくダークアイコンが付いたアプリの一覧が一度だけ表示されます。レイアウトのアイデアをもっと探しているなら、[iOS 27のホーム画面アイデア](/blog/ios-27-home-screen-ideas)もどうぞ。

## そのまま残るもの

ダークアイコンはきれいに見えることを優先しているため、いくつかはそのままです。

- **もともと暗いアイコン**や、きれいに色を変えるには複雑すぎるアイコンはそのまま表示されます。
- **Webサイト**はサイトのアイコンのままです。
- **Liquid Glassウィジェット**はシステムに自動で追従できないので、「ダークアイコンの外観」で**ライト**か**ダーク**を選んでください。

## よくある質問

**iPhoneのダークモードで白いままのアプリアイコンがあるのはなぜ？**
ダークアイコンがきれいに表示されるのは開発者がダーク版を用意している場合だけで、用意していないアプリも多くあります。WidgetLoftのウィジェットは、用意済み、Apple純正、デバイス上で作るダークアイコンでその穴を埋めます。

**WidgetLoftはダーク版を作るためにアイコンをアップロードしますか？**
いいえ。カタログにないアプリのダークアイコンは、そのアプリ自身のアイコンからスマホ上で直接作られます。何もアップロードされません。

**Liquid Glassウィジェットが自動でダークアイコンに切り替わらないのはなぜ？**
Liquid Glassウィジェットはシステムの外観に自動で追従できません。「設定」→「ウィジェット」→「ダークアイコンの外観」で、ライトかダークを選んでください。
