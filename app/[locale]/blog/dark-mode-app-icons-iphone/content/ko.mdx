# iPhone에서 모든 앱 아이콘을 다크 모드로 바꾸는 방법

**빠른 답변:** iOS는 앱 개발자가 다크 아이콘을 넣어 둔 경우에만 제대로 된 다크 아이콘을 보여줄 수 있어서, 많은 앱이 밝은 채로 남습니다. 모든 앱을 다크 아이콘으로 쓰고 싶다면 [WidgetLoft](/widgetloft) (구 FolderMini) 위젯에 앱을 넣으세요. 인기 앱은 미리 준비된 다크 아이콘이 있고, Apple 앱은 Apple의 실제 다크 아이콘을 쓰며, 나머지 앱도 추가할 때 iPhone에서 바로 다크 아이콘이 만들어집니다.

다크 아이콘을 켜니 홈 화면이 멋져졌는데, 구석에 있는 하얀 은행 앱이나 쨍한 쇼핑 앱 아이콘 하나가 눈에 거슬리죠. 왜 그런지, 어떻게 해결하는지 알려드릴게요.

---

## 다크 모드에서도 일부 아이콘이 밝게 남는 이유

다크 앱 아이콘은 iOS가 알아서 칠해 주는 것이 아닙니다. 개발자가 다크 버전을 디자인해서 앱에 넣어야 합니다. Apple 앱에는 있고 큰 앱들도 많이 갖추고 있지만, 이 업데이트를 받지 못한 앱도 아주 많습니다. 그런 앱의 아이콘은 어떤 모드를 고르든 하얗거나 밝은 배경을 그대로 유지합니다.

그 아이콘 자체는 바꿀 수 없습니다. 대신 타일에 다크 버전을 보여주는 위젯에서 그 앱을 열 수 있습니다. [WidgetLoft](/widgetloft)는 앱 그룹을 홈 화면 위젯으로 만들어 주고, 타일을 탭하면 단축어를 거치지 않고 앱이 바로 열립니다.

## 단계별 안내: 모든 앱에 다크 아이콘 적용하기

1. **그룹 만들기.** App Store에서 [WidgetLoft](/widgetloft)를 설치하고(무료로 써 볼 수 있습니다) **그룹** 탭에서 그룹을 만듭니다.
2. **앱 추가하기.** 앱 안에서 App Store를 검색하거나, App Store의 아무 앱 페이지에서 **공유 → WidgetLoft**를 사용합니다. 2.1.0의 새 기능: 카탈로그에 없는 앱도 추가할 때 앱 자체 아이콘으로 휴대폰에서 다크 아이콘이 만들어집니다. 아무것도 업로드되지 않습니다.
3. **위젯 배치하기.** 홈 화면을 길게 누르고 **+** 버튼을 탭한 뒤 WidgetLoft를 검색해 그룹 위젯을 추가합니다.
4. **아이콘 모드 고르기.** **설정 → 위젯 → 다크 아이콘 모드**로 이동합니다. 일반 위젯은 **자동**(기기 설정을 따름), **라이트**, **다크** 중에서 고릅니다.
5. **타일 하나하나 다듬기.** 나만의 스타일을 원하나요? **라이브러리**에서 타일을 탭하고 **아이콘 변경**을 눌러 라이트용과 다크용 사진을 따로 지정하세요.

## iOS 기본 다크 아이콘과 WidgetLoft 위젯 다크 아이콘 비교

| iOS 기본 다크 아이콘 | WidgetLoft 위젯 다크 아이콘 |
| --- | --- |
| 개발자가 만든 만큼만 어두워짐 | 인기 앱용으로 미리 준비된 다크 아이콘 |
| Apple 앱은 Apple의 다크 아이콘 사용 | Apple 앱은 여기서도 Apple의 실제 다크 아이콘 사용 |
| 다크 버전이 없는 앱은 밝은 채로 남음 | 나머지 앱도 추가할 때 iPhone에서 다크 아이콘 생성 |
| 아이콘은 앱에 들어 있는 그대로 | 모든 타일에 라이트용, 다크용 사진을 따로 지정 |
| 시스템 모드를 따름 | 설정 → 위젯에서 자동, 라이트, 다크 선택 |

결과적으로 다크 아이콘을 내놓은 적 없는 앱까지 포함해 모든 타일이 어울리는 홈 화면이 됩니다. 이미 WidgetLoft를 쓰고 있다면, 새로 다크 아이콘을 받은 앱 목록이 한 번 표시됩니다. 레이아웃 아이디어가 더 필요하다면 [iOS 27 홈 화면 아이디어](/blog/ios-27-home-screen-ideas)도 참고하세요.

## 그대로 남는 것

다크 아이콘은 깔끔하게 보이도록 만들어지기 때문에 몇 가지는 손대지 않습니다.

- **이미 어두운 아이콘**이나 깔끔하게 색을 바꾸기에는 너무 복잡한 아이콘은 그대로 둡니다.
- **웹사이트**는 사이트 아이콘을 그대로 씁니다.
- **Liquid Glass 위젯**은 시스템을 자동으로 따라갈 수 없으니, 다크 아이콘 모드에서 **라이트**나 **다크**를 직접 고르세요.

## 자주 묻는 질문

**iPhone 다크 모드에서 일부 앱 아이콘이 하얗게 남는 이유는 무엇인가요?**
다크 아이콘은 개발자가 다크 버전을 넣어야 제대로 보이는데, 그렇지 않은 앱이 많습니다. WidgetLoft 위젯은 미리 준비된 아이콘, Apple 아이콘, 기기에서 만든 다크 아이콘으로 그 빈틈을 채웁니다.

**WidgetLoft가 다크 버전을 만들려고 제 아이콘을 업로드하나요?**
아니요. 카탈로그에 없는 앱의 다크 아이콘은 앱 자체 아이콘을 바탕으로 휴대폰에서 바로 만들어집니다. 아무것도 업로드되지 않습니다.

**Liquid Glass 위젯이 자동으로 다크 아이콘으로 바뀌지 않는 이유는 무엇인가요?**
Liquid Glass 위젯은 시스템 모드를 스스로 따라갈 수 없습니다. 설정 → 위젯 → 다크 아이콘 모드에서 라이트나 다크를 직접 고르세요.
