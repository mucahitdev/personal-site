# Как открыть сайт в Chrome (или любом другом браузере) из виджета на iPhone

**Короткий ответ:** сайты, добавленные на экран «Домой» iPhone, открываются в Safari или в браузере по умолчанию, и поменять это для отдельной ссылки нельзя. В [WidgetLoft](/widgetloft) (ранее FolderMini) вы добавляете сайт как плитку виджета и выбираете Chrome, Firefox, Brave, другой браузер или полноэкранный просмотр в Настройки → Виджет → Открытие сайтов, для всех сайтов или только для одного.

Допустим, Safari у вас по умолчанию, а рабочая панель живёт в Chrome. Одно касание на экране «Домой» всё равно должно вести туда, куда нужно.

---

## Почему сайты с экрана «Домой» всегда открываются в Safari

Функция **«На экран Домой»** в Safari создаёт закладку, которая принадлежит Safari. Большинство виджетов со ссылками приводят туда же: они передают адрес **браузеру по умолчанию**.

Смена браузера по умолчанию меняет каждую ссылку в каждом приложении. Обычно хочется точечного решения: *этот* сайт в Chrome, а всё остальное как раньше. Именно так работают плитки сайтов в WidgetLoft: один браузер для всех сайтов и отдельный выбор для любого конкретного сайта.

## Пошагово: открываем сайт в Chrome из виджета

1. **Добавьте сайт как плитку.** В [WidgetLoft](/widgetloft) откройте **Библиотека** → **Добавить плитки** → **Веб-сайт** и вставьте адрес. Значок и название сайта заполнятся сами.
2. **Поместите его в виджет.** Добавьте плитку в группу, затем добавьте виджет WidgetLoft на экран «Домой» (нажмите и удерживайте экран «Домой», нажмите **+**, найдите WidgetLoft).
3. **Выберите браузер для всех сайтов.** Откройте **Настройки** → **Виджет** → **Открытие сайтов** и выберите Safari, Chrome, Firefox, Edge, Brave, DuckDuckGo, Opera, Opera GX, Aloha или Yandex. Или выберите **Внутри WidgetLoft** для полноэкранного просмотра.
4. **Измените один сайт (по желанию).** Откройте плитку сайта, нажмите **Открывать в** и выберите другой вариант. Это касается только этого сайта. **Как в настройках** возвращает общий выбор.
5. **Добавьте свой браузер (по желанию).** Нет в списке? Откройте **Свои браузеры** → **Добавить браузер**, укажите название и формат адреса, содержащий `{url}`, затем нажмите **Проверить**.

## Какой вариант выбрать

| Вариант | Когда подходит |
| --- | --- |
| Браузер по умолчанию | Вас устраивает браузер, которым пользуется весь остальной iPhone |
| Выбранный браузер (Chrome, Firefox, Brave и другие) | Закладки, пароли или расширения хранятся в браузере, который не используется по умолчанию |
| Внутри WidgetLoft | Нужен сайт на весь экран без вкладок, с кнопкой **Открыть в браузере**, когда она понадобится |
| Свой браузер | Вашего браузера нет в списке, и вы знаете его формат адреса |

Их можно свободно сочетать. Оставьте общую настройку [WidgetLoft](/widgetloft) на любимом браузере, а один банковский или рабочий сайт через **Открывать в** направьте в другое место.

## Чего ожидать

- **Сначала на мгновение открывается WidgetLoft**, если выбран любой вариант, кроме браузера по умолчанию. С браузером по умолчанию сайт открывается сразу.
- **Если выбранный браузер не установлен**, сайт откроется в браузере по умолчанию.
- **Входы в браузере WidgetLoft не связаны с Safari**, поэтому, возможно, там придётся войти ещё раз.
- **Это не режим веб-приложения.** Внутри WidgetLoft это полноэкранный просмотр в браузере, а не отдельно установленное веб-приложение.
- **Работает и из Dynamic Island.** Если у вас включена Панель быстрого запуска, плитки сайтов в Dynamic Island и в баннере на экране блокировки открываются в выбранном браузере.

Сайты стоят рядом с приложениями в том же виджете. Про плитки приложений читайте, [как запускать приложения из виджета](/blog/launch-apps-from-widgets-ios).

## Частые вопросы

**Почему сайт с экрана «Домой» всегда открывается в Safari?**
Закладка, созданная через «На экран Домой» в Safari, открывается в Safari, а большинство виджетов со ссылками используют браузер по умолчанию. Плитка сайта в [WidgetLoft](/widgetloft) позволяет выбрать браузер самому.

**Что будет, если выбранный браузер не установлен?**
Сайт откроется в браузере по умолчанию, так что плитка всё равно сработает.

**Буду ли я авторизован на сайтах внутри WidgetLoft?**
Входы там не связаны с Safari, поэтому, возможно, придётся войти один раз. Хотите пользоваться текущими сессиями? Выберите свой обычный браузер.
