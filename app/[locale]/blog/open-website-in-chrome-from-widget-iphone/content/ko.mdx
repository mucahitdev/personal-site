# iPhone 위젯에서 웹사이트를 Chrome(또는 원하는 브라우저)으로 여는 방법

**빠른 답변:** iPhone 홈 화면에 추가한 웹사이트는 Safari나 기본 브라우저에서 열리며, 링크마다 바꿀 수는 없습니다. [WidgetLoft](/widgetloft) (구 FolderMini)에서는 사이트를 위젯 타일로 추가한 뒤 설정 → 위젯 → 웹사이트 열기에서 Chrome, Firefox, Brave, 다른 브라우저 또는 전체 화면 보기를 고를 수 있습니다. 모든 사이트에 한 번에, 또는 한 사이트만 설정할 수 있어요.

기본 브라우저는 Safari인데 업무용 대시보드는 Chrome에서 쓰고 있을 수 있죠. 그래도 홈 화면에서 한 번 탭하면 제자리로 가야 합니다.

---

## 홈 화면 웹사이트가 항상 Safari에서 열리는 이유

Safari의 **홈 화면에 추가**는 Safari에 속한 북마크를 만듭니다. 대부분의 링크 위젯도 결국 같은 곳으로 갑니다. 주소를 **기본 브라우저**로 넘기죠.

기본 브라우저를 바꾸면 모든 앱의 모든 링크가 바뀝니다. 보통 원하는 건 더 좁은 범위입니다. *이* 사이트만 Chrome으로, 나머지는 그대로요. WidgetLoft의 웹사이트 타일이 바로 그렇게 동작합니다. 모든 웹사이트에 쓸 브라우저 하나를 정하고, 원하는 사이트만 따로 바꿀 수 있습니다.

## 단계별: 위젯에서 웹사이트를 Chrome으로 열기

1. **웹사이트를 타일로 추가하세요.** [WidgetLoft](/widgetloft)에서 **라이브러리** → **타일 추가** → **웹사이트**로 가서 주소를 붙여 넣습니다. 사이트 아이콘과 이름은 자동으로 채워집니다.
2. **위젯에 넣으세요.** 타일을 그룹에 추가한 다음 WidgetLoft 위젯을 홈 화면에 추가합니다(홈 화면을 길게 누르고 **+** 버튼을 탭한 뒤 WidgetLoft 검색).
3. **모든 웹사이트에 쓸 브라우저를 고르세요.** **설정** → **위젯** → **웹사이트 열기**에서 Safari, Chrome, Firefox, Edge, Brave, DuckDuckGo, Opera, Opera GX, Aloha, Yandex 중 하나를 고릅니다. 전체 화면으로 보려면 **WidgetLoft 안에서**를 선택하세요.
4. **한 사이트만 바꾸기(선택).** 웹사이트 타일을 열고 **여는 곳**을 탭한 뒤 다른 옵션을 고릅니다. 그 웹사이트에만 적용됩니다. **설정 따르기**를 고르면 원래대로 돌아갑니다.
5. **사용자 지정 브라우저 추가(선택).** 목록에 없나요? **사용자 지정 브라우저** → **브라우저 추가**에서 이름과 `{url}`이 들어간 주소 형식을 입력하고 **테스트**를 탭하세요.

## 어떤 옵션을 고를까

| 옵션 | 이럴 때 쓰세요 |
| --- | --- |
| 기본 브라우저 | iPhone의 다른 곳에서 쓰는 브라우저로 충분할 때 |
| 선택한 브라우저(Chrome, Firefox, Brave 등) | 북마크, 비밀번호, 확장 프로그램이 기본이 아닌 브라우저에 있을 때 |
| WidgetLoft 안에서 | 탭 없이 전체 화면으로 사이트를 보고, 필요할 때 **브라우저에서 열기** 버튼을 쓰고 싶을 때 |
| 사용자 지정 브라우저 | 쓰는 브라우저가 목록에 없고 그 주소 형식을 알고 있을 때 |

자유롭게 섞어 쓸 수 있습니다. [WidgetLoft](/widgetloft)의 전체 설정은 좋아하는 브라우저로 두고, 은행이나 업무 사이트 하나만 **여는 곳**으로 다른 곳에서 열리게 하면 됩니다.

## 알아 두면 좋은 점

- **WidgetLoft가 잠깐 먼저 열립니다.** 기본 브라우저가 아닌 옵션을 골랐을 때입니다. 기본 브라우저라면 사이트가 바로 열립니다.
- **선택한 브라우저가 설치되어 있지 않으면** 사이트는 기본 브라우저에서 열립니다.
- **WidgetLoft 브라우저의 로그인은 Safari와 별개**라서, 거기서 한 번 더 로그인해야 할 수 있습니다.
- **웹 앱 모드는 아닙니다.** WidgetLoft 안에서는 전체 화면 브라우저 보기이며, 따로 설치되는 웹 앱이 아닙니다.
- **Dynamic Island에서도 됩니다.** 빠른 실행 바를 쓰고 있다면 Dynamic Island와 잠금 화면 배너의 웹사이트 타일도 선택한 브라우저에서 열립니다.

웹사이트는 같은 위젯 안에서 앱과 나란히 놓입니다. 앱 타일은 [위젯에서 앱을 실행하는 방법](/blog/launch-apps-from-widgets-ios)을 참고하세요.

## 자주 묻는 질문

**홈 화면의 웹사이트가 왜 항상 Safari에서 열리나요?**
Safari의 홈 화면에 추가로 만든 북마크는 Safari에서 열리고, 대부분의 링크 위젯은 기본 브라우저를 씁니다. [WidgetLoft](/widgetloft) 웹사이트 타일은 브라우저를 직접 고를 수 있습니다.

**선택한 브라우저가 설치되어 있지 않으면 어떻게 되나요?**
웹사이트가 기본 브라우저에서 열리므로 타일은 그대로 동작합니다.

**WidgetLoft 안에서 연 사이트에도 로그인되어 있나요?**
그곳의 로그인은 Safari와 별개라 한 번 로그인해야 할 수 있습니다. 기존 로그인 상태가 좋다면 평소 쓰는 브라우저를 고르세요.
