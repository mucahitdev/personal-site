# How to Open a Website in Chrome (or Any Browser) from an iPhone Widget

**Quick answer:** Websites you add to the iPhone Home Screen open in Safari or your default browser, and you can't change that per link. With [WidgetLoft](/widgetloft) (formerly FolderMini) you add the site as a widget tile, then choose Chrome, Firefox, Brave, another browser or a full-screen view in Settings → Widget → Opening Websites, for every site or just one.

Maybe Safari is your default but your work dashboard lives in Chrome. One tap on your Home Screen should land in the right place.

---

## Why Home Screen websites always open in Safari

Safari's **Add to Home Screen** creates a bookmark that belongs to Safari. Most link widgets end in the same place: they pass the address to your **default browser**.

Changing the default browser changes every link in every app. What you usually want is narrower: *this* site in Chrome, everything else as usual. WidgetLoft's website tiles do exactly that: one browser for all websites, with an override for any single site.

## Step-by-step: open a website in Chrome from a widget

1. **Add the website as a tile.** In [WidgetLoft](/widgetloft), go to **Library** → **Add Tiles** → **Website** and paste the address. The site icon and name are filled in for you.
2. **Put it in a widget.** Add the tile to a group, then add the WidgetLoft widget to your Home Screen (long-press the Home Screen, tap **+**, search for WidgetLoft).
3. **Choose a browser for all websites.** Go to **Settings** → **Widget** → **Opening Websites** and pick Safari, Chrome, Firefox, Edge, Brave, DuckDuckGo, Opera, Opera GX, Aloha or Yandex. Or pick **Inside WidgetLoft** for a full-screen view.
4. **Override one site (optional).** Open the website tile, tap **Opens in** and choose another option. It applies to that website only. **Use the setting** puts it back.
5. **Add a custom browser (optional).** Not on the list? Go to **Custom browsers** → **Add Browser**, give it a name and an address format containing `{url}`, then tap **Try It**.

## Which option to pick

| Option | When to use it |
| --- | --- |
| Default browser | You're happy with the browser the rest of your phone uses |
| A chosen browser (Chrome, Firefox, Brave and more) | Your bookmarks, passwords or extensions live in a browser that isn't your default |
| Inside WidgetLoft | You want the site full-screen with no browser tabs, with an **Open in Browser** button when you need it |
| Custom browser | Your browser isn't in the list and you know its address format |

You can mix these freely. Keep the global setting on your favorite browser in [WidgetLoft](/widgetloft), then set a single banking or work site to open somewhere else with **Opens in**.

## What to expect

- **WidgetLoft opens for a moment first** when you choose anything other than the default browser. With the default browser, the site opens directly.
- **If the chosen browser isn't installed**, the site opens in your default browser.
- **Sign-ins inside WidgetLoft's browser are separate from Safari**, so you might sign in once more there.
- **It is not a web-app mode.** Inside WidgetLoft is a full-screen browser view, not a standalone installed web app.
- **It works from the Dynamic Island too.** If you use the Quick Launch bar, website tiles in the Dynamic Island and the Lock Screen banner open in the browser you picked.

Websites sit next to your apps in the same widget. For app tiles, see [how to launch apps from a widget](/blog/launch-apps-from-widgets-ios).

## Common questions

**Why does my Home Screen website always open in Safari?**
A bookmark made with Safari's Add to Home Screen opens in Safari, and most link widgets use your default browser. A [WidgetLoft](/widgetloft) website tile lets you choose the browser instead.

**What happens if the browser I picked is not installed?**
The website opens in your default browser, so the tile still works.

**Am I signed in to websites inside WidgetLoft?**
Sign-ins there are separate from Safari, so you may need to sign in once. Prefer your existing sessions? Pick your usual browser.
