# iPhoneで重複した写真を見つけて削除する方法（ストレージを解放）

**手早い答え：** iPhoneの重複写真を整理するには、ライブラリをスキャンして、まったく同じ写真とほぼ同じ写真をグループ化するアプリを使いましょう。そうすれば一番良いものを残して残りを削除できます。[FaceIdent](/faceident)はこれをデバイス内で行い——何もアップロードされません——削除した写真は30日間「最近削除した項目」に入るので、安心して確認・整理できます。

連写や撮り直し、保存した複製は、気づかないうちにギガバイト単位で容量を食います。それらをグループ化すれば、整理は一日仕事ではなく数タップで済みます。

---

## なぜ重複がたまるのか

良い一枚を撮るために3枚撮る、写真を2回保存する、スクリーンショットのスクリーンショットを残す——そのたびに、ほぼ同じ複製が増えていきます。長いタイムラインの中では、似たようなコマが何十枚も並んでいるため、見つけるのが難しいのです。

重複検索ツールは写真を比較し、**同じに見えるものをグループ化する**ので、延々とスクロールする代わりに、グループごとに一度判断すれば済みます。

## ステップバイステップ：重複写真を削除する

1. **重複検索アプリをインストールする。** App Storeから[FaceIdent](/faceident)をダウンロードし、写真へのアクセスを許可します。
2. **デバイス内でスキャンする。** アプリがiPhone上でライブラリを比較し、まったく同じ写真とほぼ同じ写真をグループ化します。何もアップロードされません。
3. **各グループを確認する。** グループを開き、最もシャープな、または構図の良い写真を残し、他を選択します。
4. **削除または非表示にする。** 余分なものを取り除いてストレージを取り戻します。削除した写真は、気が変わったときのために30日間「最近削除した項目」に残ります。

## 重複クリーナーで見るべきポイント

| 機能 | なぜ重要か |
| --- | --- |
| ほぼ同じ写真の検出 | 完全な複製だけでなく、連写や似た写真も見つける |
| グループ単位の確認 | 一枚ずつではなく、グループごとに一度判断できる |
| 一番良い写真を残す | 削除する前に画質を比較できる |
| 安全な削除 | 余分な写真は「最近削除した項目」へ、30日間は復元可能 |
| デバイス内で処理 | 比較のためにライブラリがアップロードされることはない |

[FaceIdent](/faceident)はこれらすべてをデバイス内で行い、さらに顔やペットのグループ化、写真検索も備えています——だから整理は、ライブラリ全体を整えることの一部になります。

## よくある質問

**iPhoneで重複した写真はどうやって見つけますか？**
写真アプリの「重複項目」アルバム、またはFaceIdentのように、まったく同じ写真とほぼ同じ写真をデバイス内でグループ化するアプリを使いましょう。

**ほぼ同じ写真も検出できますか？**
はい。FaceIdentは、標準アルバムが見逃しがちな連写系の似た写真を見つけます。

**写真はすぐに消えますか？**
いいえ。「最近削除した項目」に移動し、30日間は復元できます。
