# iPhoneのダイナミックアイランドにお気に入りのアプリを置く方法

**手っ取り早い答え：** iOSには、ダイナミックアイランドにアプリのショートカットを固定する設定がありません。そこに表示されるのはライブアクティビティだけです。[WidgetLoft](/widgetloft) （旧FolderMini）はまさにそれを活用します。クイック起動バーはグループのひとつをそのまま映すライブアクティビティで、ダイナミックアイランドに最大5個、ロック画面に最大10個のアプリを置けます。

ダイナミックアイランドはいつも目に入る場所にあるので、一日中開くアプリを置くのにぴったりです。1分ほどで設定する方法を紹介します。

---

## ダイナミックアイランドにアプリのショートカットを置けない理由

Appleはダイナミックアイランドをライブアクティビティのために作りました。タイマー、フードデリバリー、試合のライブスコアなどです。アプリのアイコンをドラッグして入れることはできず、固定する設定もありません。ロック画面のライブアクティビティのバナーも同じです。

そこで、中身が自分のアプリの列になっているライブアクティビティを使うのがコツです。WidgetLoftの**クイック起動バー**はまさにそれを行います。アプリ内のグループを同じアイコンのまま映し出し、アイランドとロック画面に表示し続けます。

## 手順：ダイナミックアイランドにアプリを置く

1. **グループを作る。** [WidgetLoft](/widgetloft) を開き、「グループ」タブでグループを作って、よく使うアプリを追加します。アイランドに表示されるのは最大5個なので、5個のグループならすべて収まります。
2. **クイック起動バーをオンにする。** 設定 → **ダイナミックアイランドとライブアクティビティ** を開き、**クイック起動バー**をオンにします。
3. **フォルダを選ぶ。** **フォルダ**で、今作ったグループを選びます。
4. **ライブアクティビティを許可する。** 何も表示されない場合は、iOSの設定アプリでWidgetLoftを探し、ライブアクティビティが許可されているか確認します。
5. **アイランドを長押ししてアプリをタップ。** 小さい状態のアイランドにはグリッドのアイコンとアプリの数が表示されます。長押しして列を広げ、好きなアイコンをタップします。

## ダイナミックアイランドとロック画面のバナーの比較

| | ダイナミックアイランド | ロック画面のバナー |
| --- | --- | --- |
| 表示されるアプリ | 最大5個 | 最大10個 |
| 列 | 1列 | 5個までは1列、6から10個は2列 |
| タップしたときの動き | ワンタップでアプリを直接開く | まずFace IDでロック解除を求め、その後アプリを開く |
| Webサイトのタイル | 選んだブラウザで開く | 選んだブラウザで開く |
| 見た目 | 小さい状態：グリッドのアイコンとアプリの数 | グループの色で色付け、透明グループならシステムのLiquid Glass |

ダイナミックアイランドからのワンタップ起動は [WidgetLoft](/widgetloft) 2.1.0の新機能です。WidgetLoftを経由せず、アプリがすぐに開きます。ロック画面ではiPhoneがまだロックされているので、Face IDで確認してからアプリが開きます。ロック画面全体を作り直すなら、[iOS 27のロック画面の設定方法](/blog/ios-27-lock-screen-setup)もあわせてご覧ください。

## よくある質問

**ダイナミックアイランドからアプリが消えたのはなぜですか？**
iOSはライブアクティビティを数時間後（アクティブな状態で約8時間）に終了します。WidgetLoftはアプリを開くたびにクイック起動バーを再開するので、少しアプリを開けば元に戻ります。

**ダイナミックアイランドに6個以上のアプリを置けますか？**
いいえ。広げたアイランドには1列に最大5個のアプリが表示されます。ロック画面のバナーには同じグループのアプリが2列で最大10個表示されます。

**クイック起動バーは完成した機能ですか？**
アプリ内ではベータ版と表示されています。iOSのライブアクティビティを使うため、WidgetLoftのライブアクティビティを許可する必要があり、iOSが定める時間制限にも従います。
