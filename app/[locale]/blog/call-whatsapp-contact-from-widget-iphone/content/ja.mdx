# iPhoneのホーム画面ウィジェットから連絡先に電話やWhatsAppをする方法

**手っ取り早い答え：** iPhoneには昔ながらの短縮ダイヤルはありませんが、ウィジェットに置いた連絡先タイルがその役割を果たします。[WidgetLoft](/widgetloft) （旧FolderMini）でライブラリ、タイルを追加、連絡先と進み、相手と「電話」や「WhatsApp」などの操作を選んで、タイルをウィジェットに置くだけ。ワンタップで電話がかかり、またはチャットが開きます。

いちばんよく話す相手が、3画面も奥にいる必要はありません。ホーム画面に直接置く方法を紹介します。

---

## 連絡先ウィジェットが本当の短縮ダイヤルにならない理由

Appleの連絡先ウィジェットは選んだ人を表示してくれるので、出発点としては十分です。ただし、タップしても道のりは半分だけ。開いた後に、何をするか（電話、メッセージ、FaceTime）をまだ選ぶ必要があります。パートナーに1日に何度も電話するなら、このひと手間は積み重なります。

WidgetLoftの連絡先タイルなら、その手間がありません。操作はタイルを設定するときに一度決めるだけで、その後はタップするたびにその操作だけを行います。選択肢を残したい場合は、相手のすべての操作をまとめた小さなフォルダにすることもできます。

## 手順：ホーム画面のウィジェットに連絡先を追加する

1. **連絡先タイルを追加する。** [WidgetLoft](/widgetloft) を開き、**ライブラリ** タブで **タイルを追加**、続いて **連絡先** をタップします。
2. **相手を選ぶ。** **「連絡先」から選択** をタップして相手を選びます。連絡先へのアクセス許可は必要ありません。名前、電話番号、メールアドレスを自分で入力することもできます。
3. **操作を選ぶ。** タイルでできることを選びます：電話、メッセージ、FaceTime、FaceTimeオーディオ、メール、WhatsApp、Telegram。次に **1つの操作だけ**（1回のタップで1つの操作）か、**すべての操作が入ったフォルダ**（相手をタップしてから操作をタップ）を選びます。
4. **アイコンを選ぶ。** **Appのアイコン**、相手の写真を使う **写真**、写真に小さなバッジを組み合わせる **写真＋バッジ** から選びます。
5. **ウィジェットに置く。** タイルをグループに追加します。ホーム画面を長押ししてWidgetLoftのウィジェットを追加し、そのグループを選びます。

## タップしたときに各操作が行うこと

| 操作 | タップすると |
| --- | --- |
| 電話 | 相手に電話をかけます |
| メッセージ | その相手とのメッセージの会話を開きます |
| FaceTime または FaceTimeオーディオ | FaceTimeのビデオ通話または音声通話を始めます |
| メール | 相手のアドレス宛てのメールを開きます |
| WhatsApp | その相手とのWhatsAppチャットを開きます |
| Telegram | ユーザ名または電話番号で相手のTelegramチャットを開きます |

連絡先タイルは通常のアプリタイルと並べて使えるので、1つの [WidgetLoft](/widgetloft) グループに家族の顔と、連絡に使うアプリをまとめられます。大切な3人を集めた小サイズのウィジェットや、連絡先とアプリを混ぜた中サイズのウィジェットを作ってみましょう。ランチャーウィジェットが初めてなら、[ウィジェットから任意のアプリを起動する方法](/blog/launch-apps-from-widgets-ios)もご覧ください。

## 連絡先タイルでできないこと

あとで驚かないように、正直に制限をお伝えします。

- **通話を直接始めるのは電話とFaceTimeだけです。** WhatsAppとTelegramのタイルはトーク画面を開きます。そこで音声通話やビデオ通話をしたい場合は、チャット内の通話ボタンをタップしてください。
- **Telegramにはユーザ名か電話番号が必要です。** どちらでも使えます。相手のTelegramアカウントが別の番号なら、その番号を入力してください。
- **すべてのメッセージアプリに対応しているわけではありません。** Viber、Messenger、LINE用の操作はありません。これらは、アプリそのものを通常のタイルとして追加してください。

## よくある質問

**iPhoneのホーム画面に短縮ダイヤルを作れますか？**
はい。Appleの連絡先ウィジェットは人を表示しますが、操作はタップした後に選びます。WidgetLoftの連絡先タイルは、電話をかける、チャットを開くなど、1回のタップで1つの操作を実行します。

**ウィジェットから特定の相手とのWhatsAppチャットを開けますか？**
はい。操作にWhatsAppを選ぶと、タイルはその相手とのチャットを開きます。通話を始めるのではなく、トーク画面を開きます。Telegramも同じように動作し、ユーザ名または電話番号を使えます。

**WidgetLoftは連絡先へのアクセスが必要ですか？**
いいえ。「連絡先」から選択は、連絡先へのアクセスを許可しなくても使えます。情報を手で入力することもできます。
