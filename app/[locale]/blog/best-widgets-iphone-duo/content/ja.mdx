# iPhone Duoの7.6インチ内側ディスプレイにおすすめのウィジェット

**手っ取り早い答え：** iPhone Duoの7.6インチ内側ディスプレイでは、まずiOS 27の特大サイズのカレンダー、写真、ミュージック、天気のウィジェットを置き、さっと確認したい情報は左側の「今日の表示」に任せましょう。アプリを開くには [WidgetLoft](/widgetloft) （旧FolderMini）を追加します。特大ウィジェットに最大77個のアプリを置けて、フォルダの中のフォルダやダークアイコンにも対応しています。

画面が大きくなれば、ウィジェットも大きくしたくなります。この短いリストを使えば、開いたホーム画面が間延びせず、きちんと計画されたレイアウトになります。

---

## 内側ディスプレイにおすすめのウィジェット

iPhone DuoはiOS 27.1を搭載して発売され、iOS 27ではホーム画面の1ページ全体（4×6のグリッド領域）を埋める特大サイズのウィジェットが追加されます。iPhoneを開くとホーム画面には2つのページが並び、左側には縦にスクロールするウィジェットのリスト「今日の表示」があります。おすすめは次のとおりです。

- **カレンダー（特大）。** 予定を1ページまるごとで表示。
- **写真（特大）。** 写真を大きく表示。
- **ミュージック（特大）。** 音楽にワンタップでアクセス。
- **天気（特大）。** アプリを開かずに天気予報を確認。
- **今日の表示。** ページの左側にある、小さめのウィジェットをスクロールできる一覧。
- **WidgetLoft（特大）。** 最大77個のアプリを置けるランチャーページ。

## 手順：内側ディスプレイにウィジェットを追加する

1. **ホーム画面を開く。** iPhoneを開き、ウィジェットを置きたいページまでスワイプします。
2. **何もない場所を長押しする。** アイコンが揺れ始めるまで押し続けます。
3. **「編集」、次に「ウィジェットを追加」をタップ。** ウィジェットギャラリーが開きます。
4. **ウィジェットとサイズを選ぶ。** カレンダー、写真、ミュージック、天気、またはWidgetLoftを選び、サイズを特大までスワイプします。
5. **追加して配置する。** 「ウィジェットを追加」をタップし、好きな場所へドラッグして「完了」をタップします。

ウィジェットに表示するアプリがあるように、先にWidgetLoftでグループを作っておきましょう。2つのページ全体の計画は [iPhone Duoのホーム画面を設定する方法](/blog/iphone-duo-home-screen-setup) をご覧ください。

## どのウィジェットを何に使うか

| ウィジェット | 向いている用途 |
| --- | --- |
| カレンダー（特大） | 1日の予定を1ページで見る |
| 写真（特大） | 写真を大きく表示する |
| ミュージック（特大） | 音楽をすぐ手の届く場所に置く |
| 天気（特大） | 1ページ全体で天気予報を見る |
| 今日の表示 | ページを使わずにさっと確認する |
| WidgetLoft（特大） | 最大77個のアプリをそれぞれワンタップで開く |

Appleのウィジェットは情報を表示するためのものです。[WidgetLoft](/widgetloft) はもう一つの役割、つまりアプリの起動を担います。タイルをタップするとそのアプリが直接開きます。ショートカットアプリは使わず、途中でWidgetLoftが開くこともありません。

## WidgetLoftがランチャーページに向いている理由

アイコンで埋める1ページこそ、[WidgetLoft](/widgetloft) が一番活きる場所です。

- **最大77個のアプリ。** 小アイコンの場合（中アイコンで54、大で40、特大で24）。
- **フォルダの中のフォルダ。** ウィジェット上でフォルダをタップするとその場で開き、戻るタイルで1階層上に戻れます。
- **ダークアイコン。** 人気アプリには用意済みのダークアイコンがあり、Apple純正アプリはApple本物のダークアイコンを使います。App Store検索で追加したアプリには、iPhone上でダークアイコンが作られます。もともと暗いアイコンや複雑すぎるアイコンはライトのままです。
- **透明な見た目。** iOS 26以降ではグループを「透明」にでき、「WidgetLoft · Liquid Glass」ウィジェットならすりガラスのような見た目になります。
- **連絡先タイル。** ウィジェットから直接、電話、メッセージ、FaceTime、WhatsApp、Telegramで連絡できます。
- **Webサイトタイル。** Safari、Chrome、Firefoxなど、選んだブラウザでサイトを開けます。

WidgetLoftは最大6グループ、ライブラリのアプリ21個まで無料で試せます。WidgetLoft Proではこの制限と広告がなくなります。

## よくある質問

**iPhone Duoはいつ発売されますか？**
Appleは2026年9月9日に発表しました。予約注文は10月16日に始まり、発売は2026年10月23日で、iOS 27.1を搭載します。それまでは、このリストは実機での使用ではなく、Appleが発表した機能にもとづいています。

**WidgetLoftはiPhone Duoで使えますか？**
WidgetLoftのウィジェットは標準のiOSウィジェットで、iOS 27を含むiOS 18以降のすべてのiPhoneで動作します。iPhone Duo専用に作られた機能はありません。

**特大ウィジェットにはiOS 27が必要ですか？**
はい。特大サイズはiOS 27のみで、iPhone DuoはiOS 27.1を搭載して発売されます。iOS 18から26では、WidgetLoftの大サイズのウィジェットに最大49個のアプリを置けます。
