# 如何按内容搜索 iPhone 照片（物体与自然语言）

**快速回答：** 要按内容搜索照片，请使用一款能识别每张照片里的物体和场景、并让你用日常语言描述所需内容的应用。[FaceIdent](/faceident) 会在设备上为你的相册建立索引，并根据“海滩上的狗”或“生日蛋糕”这样的描述找到照片——无需上传，无需账号。

你很少记得一张照片是哪天拍的，但你记得里面*有什么*。按内容搜索契合的正是这份记忆，而不是时间线。

---

## 按内容搜索的三种方式

好的设备端照片搜索会结合几种线索：

- **物体和场景。** 应用能识别*海滩*、*蛋糕*、*汽车*或*群山*等，让你据此浏览或搜索。
- **自然语言（语义搜索）。** 你输入一句描述——“海滩上的日落”——它匹配的是*含义*，而不仅仅是精确标签。
- **照片中的文字。** 招牌、截图和收据上的文字也变得可搜索。

[FaceIdent](/faceident) 将这些融为一体，并全部在你的设备上运行。

## 分步操作：按照片里的内容搜索

1. **安装一款视觉搜索应用。** 从 App Store 下载 [FaceIdent](/faceident)，并允许访问你的照片。
2. **让它在设备上建立索引。** 应用会为物体和场景打标签，并在你的 iPhone 上准备好自然语言搜索。不上传任何内容。
3. **用日常语言搜索。** 输入你记得的内容——“红色汽车”“山上的雪”“桌上的咖啡”。
4. **进一步筛选。** 通过某个人的面孔或照片中出现的文字缩小结果范围。

## 挑选照片搜索应用时要看什么

| 功能 | 为什么重要 |
| --- | --- |
| 物体与场景标签 | 按照片里真正出现的东西浏览和搜索 |
| 自然语言搜索 | 描述一张照片，而不必记住关键词 |
| 文字（OCR）搜索 | 通过内部文字找到截图和收据 |
| 人物 + 内容结合 | 将面孔与场景结合，精准定位某一张照片 |
| 设备端 | 你的相册和索引永不离开手机 |

[FaceIdent](/faceident) 涵盖上述全部功能，还加入了设备端的人脸与宠物分组，让人物搜索和内容搜索并肩协作。

## 按内容搜索私密吗？

可以做到。当索引在本地运行时，照片以及由此衍生的一切都留在设备上。[FaceIdent](/faceident) 没有云端、没有账号，因此按内容搜索永远不会上传你的相册。

## 常见问题

**我能按照片里的内容搜索 iPhone 照片吗？**
可以。FaceIdent 会为物体和场景打标签并支持日常语言搜索，全部在设备上进行。

**什么是语义搜索？**
它把你所用词语的含义与照片内容匹配，因此即使没有确切关键词，一句描述也能找到对应的照片。

**它会上传我的照片吗？**
不会。索引完全在你的 iPhone 上建立。
