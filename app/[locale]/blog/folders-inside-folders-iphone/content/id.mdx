# Cara Membuat Folder di Dalam Folder di iPhone (Folder Bersarang)

**Jawaban singkat:** Anda tidak bisa memasukkan folder ke dalam folder lain di Layar Utama iPhone. iOS memang tidak mengizinkannya. Namun Anda bisa mendapatkan folder bersarang sungguhan di dalam widget dengan [WidgetLoft](/widgetloft) (sebelumnya FolderMini): ketuk ubin folder dan folder langsung terbuka di widget, dengan tombol kembali untuk naik, sedalam apa pun yang Anda mau.

Pernah menyeret folder ke atas folder lain lalu melihatnya terpental kembali? Anda tidak salah langkah. Ini solusi yang benar-benar berhasil.

---

## Mengapa iOS tidak bisa menumpuk folder

Folder Layar Utama hanya punya satu tingkat: Anda tidak bisa menyeret folder ke folder lain, dan tidak ada pengaturan yang mengubahnya. Jadi folder "Kerja" tidak bisa berisi folder "Rapat" dan folder "Dokumen", dan akhirnya Anda punya satu folder raksasa atau Layar Utama yang penuh folder kecil.

Widget bisa melakukan apa yang tidak bisa dilakukan folder. Di [WidgetLoft](/widgetloft), grup menjadi widget Layar Utama, dan grup bisa berisi folder, yang juga bisa berisi folder lain. Mengetuk ubin folder membuka folder itu di tempat, dan tombol kembali membawa Anda naik satu tingkat.

## Langkah demi langkah: membuat folder bersarang di iPhone

1. **Buat grup dan folder.** Instal [WidgetLoft](/widgetloft), buat grup, buka, lalu ketuk **Folder Baru**.
2. **Tambahkan app dan folder lain.** Tambahkan app ke folder. Ketuk **Folder Baru** lagi di dalamnya untuk turun satu tingkat lagi.
3. **Pilih tampilan ubin folder.** Tampilkan folder sebagai grid mini 2×2 atau 3×3 dari app di dalamnya, atau beri ikon sendiri dari foto atau SF Symbol.
4. **Pasang widget.** Tekan lama Layar Utama, ketuk **+**, tambahkan widget WidgetLoft, lalu pilih grup Anda.
5. **Atur tombol kembali dan kembali otomatis.** Di editor **Tombol Kembali**, pilih simbol (12 preset atau SF Symbol apa pun), warna simbol, warna latar, opasitas latar dari 0 hingga 100%, dan ukuran, atau ketuk **Atur Ulang ke Bawaan**. Seret tombol kembali ke slot mana pun. Lalu buka **Pengaturan → Widget → Kembali otomatis ke Folder**.

## Folder iOS vs folder WidgetLoft

| | Folder Layar Utama iOS | Folder WidgetLoft |
| --- | --- | --- |
| Folder di dalam folder | Tidak bisa | Bisa, kedalaman tanpa batas |
| Kapasitas | Hanya app, tanpa subfolder | Hingga 100 app dan 20 subfolder per folder |
| Letaknya | Di Layar Utama sebagai ikon | Di dalam widget Layar Utama, terbuka di tempat |
| Tampilan khusus | Pratinjau kecil app di dalamnya | Grid mini 2×2 atau 3×3, atau ikon sendiri dari foto atau simbol |
| Cara kembali | Ketuk di luar folder | Tombol kembali yang bisa diubah gaya dan posisinya |

Dengan [WidgetLoft](/widgetloft), satu widget bisa memuat seluruh hari Anda yang tertata dalam folder, dan setiap ubin app tetap membuka app-nya secara langsung.

## Tips agar tetap rapi

- **Kelompokkan berdasarkan rutinitas, bukan jenis app.** Folder "Pagi" berisi berita, cuaca, dan kalender lebih cepat daripada folder "Utilitas" yang harus Anda telusuri.
- **Gunakan kembali otomatis.** Dengan **Kembali otomatis ke Folder**, widget kembali ke tingkat teratas setelah Anda membuka app, setelah tidak digunakan beberapa saat (10 hingga 60 detik, bawaan 30), atau keduanya. Tidak ada lagi subfolder yang terlupa tetap terbuka.

Untuk merapikan lebih menyeluruh, baca [cara mengatur Layar Utama iPhone](/blog/organize-iphone-home-screen-2026).

## Pertanyaan umum

**Bisakah membuat folder di dalam folder di iPhone?**
Tidak dengan folder Layar Utama biasa. Widget folder seperti WidgetLoft mendukungnya: ketuk folder dan folder terbuka di dalam widget, dengan tombol kembali untuk naik.

**Berapa banyak app dan subfolder yang muat di satu folder?**
Hingga 100 app dan 20 subfolder per folder, tanpa batas kedalaman. Versi gratis mengizinkan 6 grup dan 21 app di pustaka; WidgetLoft Pro menghapus batas tersebut.

**Apakah folder bersarang berfungsi di widget Layar Terkunci?**
Tidak. Widget Layar Terkunci hanya menampilkan satu baris app tingkat teratas. Folder bersarang berfungsi di widget Layar Utama.
