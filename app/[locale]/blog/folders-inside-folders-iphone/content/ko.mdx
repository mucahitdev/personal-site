# 아이폰에서 폴더 안에 폴더 넣는 방법 (중첩 폴더)

**빠른 답변:** 아이폰 홈 화면에서는 폴더 안에 다른 폴더를 넣을 수 없습니다. iOS가 아예 허용하지 않습니다. 하지만 [WidgetLoft](/widgetloft) (구 FolderMini)를 쓰면 위젯 안에서 진짜 중첩 폴더를 만들 수 있습니다. 폴더를 탭하면 위젯 안에서 바로 열리고, 뒤로 버튼으로 위로 올라가며, 원하는 만큼 깊이 만들 수 있습니다.

폴더를 다른 폴더 위로 끌어다 놓았는데 튕겨 나왔나요? 잘못 조작한 게 아닙니다. 실제로 통하는 방법을 소개합니다.

---

## iOS가 폴더를 중첩하지 못하는 이유

홈 화면 폴더는 한 단계뿐입니다. 폴더를 다른 폴더로 드래그할 수 없고, 이를 바꾸는 설정도 없습니다. 그래서 "업무" 폴더 안에 "회의" 폴더와 "문서" 폴더를 둘 수 없고, 결국 거대한 폴더 하나 아니면 작은 폴더로 가득 찬 홈 화면이 됩니다.

폴더가 못 하는 일을 위젯은 할 수 있습니다. [WidgetLoft](/widgetloft)에서는 그룹이 홈 화면 위젯이 되고, 그룹에는 폴더를, 그 폴더에는 또 폴더를 넣을 수 있습니다. 폴더 타일을 탭하면 그 자리에서 폴더가 열리고, 뒤로 버튼을 누르면 한 단계 위로 올라갑니다.

## 단계별 안내: 아이폰에서 중첩 폴더 만들기

1. **그룹과 폴더 만들기.** [WidgetLoft](/widgetloft)를 설치하고 그룹을 만든 뒤 열어서 **새 폴더**를 탭합니다.
2. **앱과 폴더 더 추가하기.** 폴더에 앱을 추가합니다. 한 단계 더 들어가려면 그 안에서 다시 **새 폴더**를 탭합니다.
3. **폴더 타일 모양 고르기.** 안에 든 앱을 2×2 또는 3×3 미니 그리드로 보여주거나, 사진이나 SF Symbol로 전용 아이콘을 지정합니다.
4. **위젯 배치하기.** 홈 화면을 길게 누르고 **+** 버튼을 탭한 다음 WidgetLoft 위젯을 추가하고 그룹을 선택합니다.
5. **뒤로 버튼과 자동 복귀 설정하기.** **뒤로 버튼** 편집기에서 심볼(프리셋 12개 또는 모든 SF Symbol), 심볼 색상, 배경 색상, 0에서 100%까지의 배경 불투명도, 크기를 고르거나 **기본값으로 재설정**을 탭합니다. 뒤로 버튼은 원하는 칸으로 드래그할 수 있습니다. 그다음 **설정 → 위젯 → 폴더로 자동 복귀**로 이동합니다.

## iOS 폴더와 WidgetLoft 폴더 비교

| | iOS 홈 화면 폴더 | WidgetLoft 폴더 |
| --- | --- | --- |
| 폴더 안의 폴더 | 불가능 | 가능, 깊이 무제한 |
| 용량 | 앱만 가능, 하위 폴더 없음 | 폴더당 앱 100개와 하위 폴더 20개까지 |
| 위치 | 홈 화면에 아이콘으로 | 홈 화면 위젯 안, 그 자리에서 열림 |
| 모양 꾸미기 | 안에 든 앱의 작은 미리보기 | 2×2 또는 3×3 미니 그리드, 또는 사진이나 심볼 전용 아이콘 |
| 돌아가기 | 폴더 바깥 탭하기 | 꾸미고 옮길 수 있는 뒤로 버튼 |

[WidgetLoft](/widgetloft)를 쓰면 위젯 하나에 하루 전체를 폴더별로 담을 수 있고, 각 앱 타일은 여전히 앱을 바로 엽니다.

## 깔끔하게 유지하는 팁

- **앱 종류가 아니라 일과별로 묶으세요.** 뉴스, 날씨, 캘린더를 담은 "아침" 폴더가 한참 뒤져야 하는 "유틸리티" 폴더보다 빠릅니다.
- **자동 복귀를 사용하세요.** **폴더로 자동 복귀**를 켜면 앱을 연 뒤, 일정 시간 사용하지 않은 뒤(10초에서 60초, 기본 30초), 또는 두 경우 모두 위젯이 최상위로 돌아갑니다. 잊고 있던 하위 폴더가 열려 있는 일은 더 이상 없습니다.

홈 화면 전체를 정리하고 싶다면 [아이폰 홈 화면 정리 방법](/blog/organize-iphone-home-screen-2026)도 읽어보세요.

## 자주 묻는 질문

**아이폰에서 폴더 안에 폴더를 넣을 수 있나요?**
일반 홈 화면 폴더로는 안 됩니다. WidgetLoft 같은 폴더 위젯은 가능합니다. 폴더를 탭하면 위젯 안에서 열리고, 뒤로 버튼으로 올라갑니다.

**폴더 하나에 앱과 하위 폴더를 몇 개까지 넣을 수 있나요?**
폴더당 앱 100개와 하위 폴더 20개까지, 깊이 제한은 없습니다. 무료 버전은 그룹 6개와 라이브러리 앱 21개까지 가능하며, WidgetLoft Pro는 이 제한을 없앱니다.

**중첩 폴더가 잠금 화면 위젯에서도 작동하나요?**
아니요. 잠금 화면 위젯은 최상위 앱을 한 줄로만 보여줍니다. 중첩 폴더는 홈 화면 위젯에서 작동합니다.
