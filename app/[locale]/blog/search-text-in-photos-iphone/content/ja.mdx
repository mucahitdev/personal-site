# iPhoneの写真内のテキストを検索する方法（スクリーンショットやレシート）

**簡単な答え：** 写真をその中の文字で見つけるには、スクリーンショット、レシート、メモを読み取ってインデックス化する、オンデバイスのテキスト認識（OCR）を備えたアプリを使いましょう。[FaceIdent](/faceident) では、覚えている単語（店名、コード、タイトルなど）を入力すると、一致する写真が表示されます。すべてはiPhone上で処理され、何もアップロードされません。

現代の写真ライブラリの半分は、スクリーンショット、レシート、チケット、ホワイトボードです。その1枚を見つける最も速い方法は、含まれている文字で検索することです。

---

## 写真内のテキスト検索の仕組み

テキスト認識（OCR）は、画像の中に印字された文字（看板、スクリーンショット、レシート）を読み取り、検索可能なテキストに変換します。ライブラリがインデックス化されると、単語を入力するだけで、キャプションやファイル名がなくても、その単語を含むすべての写真が見つかります。

[FaceIdent](/faceident) はこの認識をオンデバイスで実行するため、スクリーンショットやレシートが一切アップロードされることはありません。

## ステップバイステップ：写真内のテキストを検索する

1. **写真の文字検索アプリをインストールする。** App Storeから [FaceIdent](/faceident) をダウンロードし、写真へのアクセスを許可します。
2. **オンデバイスで読み取らせる。** アプリがスクリーンショット、レシート、メモ内の文字を認識し、iPhone上でインデックス化します。
3. **単語やフレーズを検索する。** 見た覚えのあるもの（ブランド名、住所、確認コードなど）を入力します。
4. **結果を開く。** 一致した写真をタップし、テキストをコピーまたは共有します。

## 写真の文字検索アプリで確認すべきポイント

| 機能 | なぜ重要か |
| --- | --- |
| オンデバイスOCR | スクリーンショットやレシートが一切アップロードされない |
| ライブラリ全体の高速検索 | 何千枚もの写真から1つの単語を見つける |
| オフラインで動作 | 接続がなくても検索を利用し続けられる |
| 人物や物体と組み合わせ | 写真に誰が・何が写っているかで結果を絞り込む |
| 無料でお試し | まず自分のスクリーンショットで試せる |

[FaceIdent](/faceident) は、オンデバイスの顔とペットのグループ分け、自然言語での写真検索とともに、これらすべてに対応しています。

## よくある質問

**写真内のテキストを検索できますか？**
はい。FaceIdentはオンデバイスのOCRで文字を読み取り、スクリーンショットやレシートを内容で検索できるようにします。

**オフラインでも動作しますか？**
はい。認識と検索はiPhone上で実行されます。

**写真のテキストはアップロードされますか？**
いいえ。OCRは完全にオンデバイスで行われます。
