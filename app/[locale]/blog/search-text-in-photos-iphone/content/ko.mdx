# 아이폰 사진 속 텍스트를 검색하는 방법 (스크린샷과 영수증)

**빠른 답변:** 사진을 그 안의 단어로 찾으려면, 스크린샷, 영수증, 메모를 읽고 색인화하는 온디바이스 텍스트 인식(OCR) 앱을 사용하세요. [FaceIdent](/faceident)에서는 기억나는 단어(상점 이름, 코드, 제목 등)를 입력하면 일치하는 사진을 보여줍니다. 모든 처리는 아이폰에서 이루어지며, 아무것도 업로드되지 않습니다.

현대적인 사진 라이브러리의 절반은 스크린샷, 영수증, 티켓, 화이트보드입니다. 그중 하나를 가장 빠르게 찾는 방법은 담긴 단어를 검색하는 것입니다.

---

## 사진 속 텍스트 검색의 작동 방식

텍스트 인식(OCR)은 이미지 안에 인쇄된 단어(간판, 스크린샷, 영수증)를 읽어 검색 가능한 텍스트로 변환합니다. 라이브러리가 색인화되면, 단어를 입력하는 것만으로 파일에 캡션이나 파일명이 없어도 그 단어가 포함된 모든 사진을 찾을 수 있습니다.

[FaceIdent](/faceident)는 이 인식을 기기에서 실행하므로 스크린샷과 영수증이 절대 업로드되지 않습니다.

## 단계별: 사진 속 텍스트 검색하기

1. **사진 텍스트 검색 앱을 설치하세요.** App Store에서 [FaceIdent](/faceident)를 다운로드하고 사진 접근을 허용하세요.
2. **기기에서 읽도록 하세요.** 앱이 스크린샷, 영수증, 메모 속 텍스트를 인식하여 아이폰에서 색인화합니다.
3. **단어나 문구를 검색하세요.** 본 기억이 있는 것(브랜드, 주소, 확인 코드 등)을 입력하세요.
4. **결과를 여세요.** 일치하는 사진을 탭한 다음 텍스트를 복사하거나 공유하세요.

## 사진 텍스트 검색 앱에서 확인할 점

| 기능 | 왜 중요한가 |
| --- | --- |
| 온디바이스 OCR | 스크린샷과 영수증이 절대 업로드되지 않음 |
| 빠른 전체 라이브러리 검색 | 수천 장의 사진에서 단어 하나를 찾음 |
| 오프라인 작동 | 연결이 없어도 검색이 계속 작동함 |
| 인물 및 사물과 결합 | 사진 속 인물이나 사물로 결과를 좁힘 |
| 무료로 사용해보기 | 먼저 자신의 스크린샷으로 테스트 |

[FaceIdent](/faceident)는 온디바이스 얼굴 및 반려동물 그룹화, 자연어 사진 검색과 함께 이 모든 것을 지원합니다.

## 자주 묻는 질문

**제 사진 속 텍스트를 검색할 수 있나요?**
네. FaceIdent는 온디바이스 OCR로 텍스트를 읽어 스크린샷과 영수증을 내용으로 검색할 수 있게 해줍니다.

**오프라인에서 작동하나요?**
네. 인식과 검색은 아이폰에서 실행됩니다.

**제 사진의 텍스트가 업로드되나요?**
아니요. OCR은 전적으로 기기에서 이루어집니다.
