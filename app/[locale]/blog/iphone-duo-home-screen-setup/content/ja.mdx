# iPhone Duoのホーム画面の設定方法（内側と外側のディスプレイ）

**手っ取り早い答え：** iPhone Duoは、役割の違う2つのホーム画面として計画しましょう。5.4インチの外側ディスプレイはコンパクトなランチャーウィジェットやロック画面ウィジェットで片手ですばやくアクセスするために、7.6インチの内側ディスプレイは大きなウィジェット、「今日の表示」、そして1ページのランチャーとしての特大ウィジェットのために使います。[WidgetLoft](/widgetloft)（旧FolderMini）のグループは、どちらの画面でもそのランチャーになります。

iPhone Duoは2026年10月23日に発売されます。アイコンを動かし始める前に、何をどこに置くかを今のうちに決めておきましょう。

---

## iPhone Duoのホーム画面はここが違う

iPhone DuoはApple初の折りたたみ式iPhoneです。閉じているときは5.4インチの外側ディスプレイを使います。開くと、同じ縦横比の7.6インチの内側ディスプレイになります。iOS 27.1を搭載して発売されます。

開いた状態では、ホーム画面に2ページが並び、左側に「今日の表示」（縦にスクロールするウィジェットのリスト）が表示されます。ダイナミックアイランドは側面に縦向きに配置され、Split Viewで2つのアプリを並べて使えます。

そこから見えてくるのはシンプルな役割分担です。外側のディスプレイはひとつのアプリをすばやく開くため、内側のディスプレイは一度に多くを見るため。アプリ選びについては、[iPhone Duoのカバー画面におすすめのアプリ](/blog/iphone-duo-cover-screen-apps)をご覧ください。

## 手順：iPhone Duoのホーム画面を計画して作る

1. **外側の画面を計画する。** 閉じた状態で片手で開く数個のアプリを書き出します。小サイズのウィジェットには9個のタイル、ロック画面ウィジェットには最大4個のアプリを1列で置けます。
2. **内側の画面を計画する。** 左側の「今日の表示」に置きたい大きなウィジェットを選びます。iOS 27ではホーム画面の1ページ全体を埋める特大ウィジェットも追加されたので、1ページをランチャーにするか決めましょう（小さいアイコンで最大77個のタイル）。
3. **グループを作る。** [WidgetLoft](/widgetloft)で、外側の画面用に少なめのグループ、内側の画面用に大きめのグループを作ります。アプリはアプリ内でApp Storeを検索して追加できます。
4. **ウィジェットを追加する。** ホーム画面を長押しし、**編集**、**ウィジェットを追加**の順にタップして、WidgetLoftを選びサイズを選びます。ロック画面では長押しして**カスタマイズ**をタップし、WidgetLoftのウィジェットを追加します。
5. **クイック起動バーを追加する。** WidgetLoftで**設定**、**Dynamic Island & Live Activity**の順に進み、**クイック起動バー**（ベータ）をオンにして**フォルダ**を選びます。ロック画面のバナーには最大10個のアプリを置けます。

## 外側ディスプレイと内側ディスプレイ：何をどこに置くか

| 画面 | 置くもの |
| --- | --- |
| 外側ディスプレイのホーム画面 | 片手で使う主要アプリを入れた小または中サイズのランチャー |
| ロック画面 | よく開くアプリを最大4個入れたロック画面ウィジェット |
| 内側ディスプレイの「今日の表示」 | スクロールして眺めたい大きな情報系ウィジェット |
| 内側ディスプレイのホーム画面 | 1ページのランチャーとしての特大ウィジェット |
| ロック画面のバナー | 最大10個のアプリを入れたクイック起動バー |

[WidgetLoft](/widgetloft)のウィジェットは、iOS 27を含むiOS 18以降のどのiPhoneでも動作する標準のiOSウィジェットなので、同じグループをどちらの画面でもランチャーとして使えます。ホーム画面のタイルをタップすると、ショートカットAppを経由せずにアプリが直接開きます。WidgetLoftはiPhone Duoでのテストは行っていないので、これは出発点となる計画として考えてください。

## よくある質問

**WidgetLoftのウィジェットはiPhone Duoで使えますか？**
標準のiOSウィジェットなので、iOS 27を含むiOS 18以降のどのiPhoneでも動作し、DuoはiOS 27.1を搭載して発売されます。WidgetLoftはDuoでのテストは行っておらず、Duo専用の機能もありません。

**内側と外側のディスプレイで別のアプリを使うべきですか？**
別々に計画すると便利です。外側には片手で使うアプリの短いリスト、内側には大きなウィジェットと1ページ全体のランチャーを。

**iPhone Duoのレイアウトの詳細はいつわかりますか？**
iPhone Duoの発売日は2026年10月23日です。レイアウトの細かな点は実機が手元に届いてからはっきりするので、このガイドは計画として使い、その時点で調整してください。
