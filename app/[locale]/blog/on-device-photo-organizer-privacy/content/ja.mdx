# iPhoneでプライベートにオンデバイスで写真を整理する：なぜ重要で、どう機能するのか

**手短に言うと：** オンデバイスの写真整理は、iPhone自身のチップを使ってライブラリを分析します――顔をグループ化し、被写体をタグ付けし、テキストを読み取ります――そのため何一つサーバーにアップロードされません。[FaceIdent](/faceident)はこの方式で動作します。クラウドもアカウントもなく、機内モードでも整理と検索を続けます。

あなたの写真ライブラリは、あなたが所有する最もプライベートなものの一つです。それを整理することが、コピーを他人のサーバーに渡すことを意味してはなりません。

---

## なぜオンデバイスが重要なのか

写真アプリがクラウドでライブラリを処理すると、あなたの最もプライベートな瞬間のコピーが、あなたが管理できないサーバー上に置かれます。そのコピーは流出したり、第三者から要求されたり、モデルの学習に使われたりする可能性があります。**オンデバイス処理はそのコピーを完全になくします**――分析はあなたの端末で行われ、結果もそこにとどまります。

かつてはその代償として機能面で妥協がありました。クラウドアプリの方ができることが多かったのです。その差は解消されました。今日のiPhoneは、顔のグループ化、被写体の認識、テキストの読み取り、自然言語検索をすべてローカルで実行できます。

## オンデバイスの整理の仕組み

1. **検出とグループ化。** アプリは端末のニューラルエンジンを使って顔を見つけ、人物（およびペット）ごとにまとめます。
2. **被写体・シーンのタグ付け。** 各写真は含まれるもの――*ビーチ*、*ケーキ*、*犬*――でラベル付けされ、閲覧と検索に使われます。
3. **テキスト認識（OCR）。** 写真、スクリーンショット、レシート内の文字が検索できるようになります。
4. **ローカル検索インデックス。** これらはすべて端末に保存されるため、検索は瞬時かつプライベートです。

[FaceIdent](/faceident)はすべてのステップをオンデバイスで行います。

## プライベートな写真アプリで確認すべき点

| 機能 | なぜ重要か |
| --- | --- |
| クラウドなし、アカウントなし | 流出しうるライブラリのサーバーコピーが存在しない |
| オンデバイス処理 | 顔、被写体、テキストは端末内にとどまる |
| オフラインで動作 | 整理と検索が機内モードでも動き続ける |
| 限定的な写真アクセスに対応 | 選んだ写真だけをアプリと共有できる |
| 明確なプライバシーポリシー | 信頼する前に主張を検証できる |

[FaceIdent](/faceident)はすべての項目を満たします。iPhone上で完結して動作し、クラウドもアカウントもなく、[プライバシーポリシー](/faceident/privacy-policy)には端末内に何が残るかが正確に記されています。

## よくある質問

**オンデバイスの整理とは何ですか？**
アプリはiPhone自身のプロセッサを使って写真を分析するため、写真も結果もサーバーに届きません。

**クラウドアプリよりプライベートですか？**
はい――何もアップロードされないため、侵害されたり再利用されたりするサーバーコピーがありません。FaceIdentにはクラウドもアカウントもありません。

**オフラインで動作しますか？**
はい。すべての処理と検索がローカルで実行されるため、機内モードでも動作します。
